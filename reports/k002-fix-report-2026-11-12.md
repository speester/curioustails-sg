## 1. Encoding

**Cause.** The previous staging bundle was produced by reading the UTF-8 page as ANSI/Windows-1252 and writing it back as UTF-8. Every non-ASCII character was double-encoded.

**Evidence in the old served bundle (`/outputs/`, 115,810 bytes, UTF-8 BOM `EF BB BF`):**

| Character | Correct | Old served page |
|---|---|---|
| `›` U+203A | 3 | 0 · instead 3 × `â€º` |
| `·` U+00B7 | 50 | 50 × `Â·` |
| `★` U+2605 | 20 | 0 · instead 20 × `â˜…` |

**Fix.** The bundle is now a byte-for-byte copy: Python `shutil.copyfile` for the page and every asset, no text decode/encode pass and no BOM. Nothing was injected, so no encoding conversion was needed. The build step can be re-run as:

```python
shutil.copyfile(src_html, stage_out / "index.html")   # bytes, no decode
shutil.copytree(src_assets, stage_out / "puppy-page-redesign-assets", copy_function=shutil.copyfile)
```

`outputs/puppy-page-redesign-biscuit.html` → `_k002_stage/outputs/index.html` → served `/outputs/`: all 113,651 bytes identical, SHA-256 `08fc191cfadbb2645bdae97bc8b96692cb70249b788a3f4e1476eeb1d9210eba`, no BOM (`3c 21 64` = `<!d`).

Every page in the bundle was checked: the root redirect (`index.html`, 103 bytes) and the Biscuit page. Both decode as strict UTF-8, both have zero `Â`, `â€`, `â˜…` and zero U+FFFD.

## 2. Date of birth

`src/data/available-puppies.json` has **no `dob` key** for Biscuit (ID 2938). `scripts/sync-puppies.mjs` reads the sheet's `DOB-` column only to compute age; `toJson()` does not emit it, so the JSON snapshot cannot carry the date.

The owner's live puppy feed (the SpreadSimple source the sync reads) has, for ID 2938:

```
DOB- = Date(2026,7,4)     → gviz months are 0-based → 2026-08-04
Age- = 3 Months
```

That is consistent with the feed's other rows and with Biscuit's 3-month age, so it is the real date — not invented. The page now shows:

- Passport **Born:** 4 August 2026
- Passport **Age:** About 3 months (100 days on 2026-11-12; computed from DOB)
- Passport **Going home:** Ready to go home · week 9 · 6 October 2026
- Timeline week-9 row: `About a week after the 2nd vaccination · 6 October 2026 for Biscuit`
- Meta description and About copy updated from 2 months to 3 months

No `we'll confirm her date` copy remains.
